Does this passkey give the same secret on both devices?

The PACT design has the root key derived from a passkey rather than stored anywhere — so the whole thing rests on one question this page answers: does prf.eval return the same 32 bytes when the same passkey is used somewhere else? If it does, an identity follows a person across devices for free. If it does not, that person silently becomes somebody else on their second device.

Run it on one profile or device, then the other, and compare the fingerprint. Same string means that provider is safe to derive from. Different strings mean it is not, and nothing else about it matters.
